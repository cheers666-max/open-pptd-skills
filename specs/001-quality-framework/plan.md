## Summary

    明确需求/页纲 → 共享作者说明 → 顺序或按实际工具并行写页

## Changes

### 1. 先修 skill 指令（T002–T003）

- SKILL 不再写死 task 工具、超过 4 页必须并行或 O(1) 耗时承诺。按实际工具和上下文容量选择执行方式。
- 新增一个短参考模板 reference/authoring-context.md，由作者按需填写 DESIGN_CONTEXT.md，不写生成器。包含目的/页数/编辑范围、选定风格、各页主要结论、关键数据与来源、YAML/容量/图标约束。
- 数据表只需“指标、数值、单位、时期/口径、来源位置、适用页”；政策/引用同时记录原文位置。允许本地文件、教学示例及明确假设。事实值没依据则保留待核实，不让模型补齐。
- 统一采用富文本块标量写法，禁止 emoji；fas 图标在导出修复验收后使用，未支持项用已有可用图形表达并明确说明。字号×行高×行数仅作估算，不能取代实际看图。
- 主写手在所有素材改写后复核跨页口径、重复/跳跃、来源对论点的支持及编辑范围。简单任务减少文档长度，不跳过必要核对。

### 2. 修已证实的脚本问题（T004–T006）

- image_search/search_images.py：--timeout 30 约束单后端完整尝试，--budget 120 约束整体；搜索/下载/筛选全失败均回退；进度/心跳写 stderr，tried 字段和失败码保留。用现有调度扩展截止控制，必须能终止挂起工作，不能仅在线程外停止等待。实现时只抽取必要辅助函数或小 worker。
- --offline 仅使用本地/缓存或明确允许的装饰替代。与 SKILL 封面/末页规则对齐：用户模板与装饰降级要求优先，不把渐变冒充必须真实的素材。联网按任务授权，已有授权无需每次确认，key 不自动启用 VLM。
- viewer/export：修饼图图例异常，最小化暴露实际渲染错误；修 HTML JSON 错误退出、截图子集页编号、CLI child error/signal 非成功。保留现有报告形状，不建统一质量报告层。
- PPTX：修 fas 图标转无关圆点，使用已有本地 SVG/路径；--report 直接输出 engine 原始详细报告。无法保留的图标明确报丢失；进度/warnings 写 stderr，JSON 摘要字段兼容。

### 3. 修检查与流程（T007–T009）

- validate_deck 修段落、内联字号与固定行高估算遗漏，不做 estimatedHeight+4 自动修复。
- audit_rendered 先用已知黑白/低对比样本修纯色测量；复杂背景/不确定遮挡只建议复核，解析失败不当零问题。修复验证后才接到 step4 的渲染之后，不增加一套 DOM 排版引擎。
- layout_planner 改成保留页数/页序/字段/页型的建议器；长文稿需要时使用，连续教学页允许同布局。本轮不调整 anti-slop-card-layout 数量阈值，保留原设计原则并说明启发式边界。
- 最终整理 SKILL 步骤与实际 CLI；保留默认三格式，人工看图并检查本次 warnings。既有案例只在副本上可选复验。
